# Deleting a consultation location and its calendar
## Kraken
The system doesn't allow an address to be deleted if it has a linked calendar or if it's the only address registered on the profile.
To remove an address with an active calendar, first manage the calendar settings.
Go to Settings → Calendars (Ajustes → Calendarios).
Select the calendar for that consultation location.
Click the menu at the upper right and choose Delete calendar (Eliminar calendario).
Do you see that option in the Calendars section?
